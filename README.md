# SULIMENKO

Production-quality family digital platform for sulimenko.com.

This repository is intentionally architecture-first. Application scaffolding starts only after ADR-0001 is accepted.

## Target stack

- Nuxt 4.5.x
- Vue 3.5.x (do not use Vue 3.6 until stable)
- Vue Router 5.x
- TypeScript
- Pinia
- Vue Flow 1.x stable
- elkjs
- Laravel 13
- PHP 8.5
- PostgreSQL 18
- Node.js 24 LTS

## Repository layout

```text
apps/
  web/      Nuxt application
  api/      Laravel application
docs/
  adr/      Architecture Decision Records
  architecture/
```

## Architecture status

ADR-0001 is ACCEPTED. Milestone 1 foundation is in progress.
